# 🛠️ Ratrakit

**Ratrakit** is a modern, lightweight, and modular web platform offering interactive calculators, dynamic canvas visualizers, and self-assessment practice suites. Built entirely using Vanilla Web Standards (ES6+) without reliance on heavy external frameworks.

🔗 **Live Application:** [Ratrakit Platform](https://ratra-raturamadhania.github.io/simulasi-tabel-z/)

---

## 🚀 Key Modules & Features

* **Z-Score Visualizer & Calculator:** Computes $P(Z < z)$, $P(Z > z)$, and two-tailed probabilities with real-time normal distribution curve rendering via HTML5 Canvas.
* **Biostatistics Exam Suite:** Interactive step-by-step examination module for Poisson, Binomial, and Normal distributions using MathJax rendering.
* **Epidemiology Assessment:** A 40-question randomized CBT-style quiz suite with question palette navigation, immediate feedback, and score visualization.

---

## 🛠️ Tech Stack & Engineering Concepts

* **Frontend:** HTML5, Modern CSS3 (Variables, Flexbox, Grid, Responsive Mobile-First Design)
* **Logic & State Management:** Modular Vanilla JavaScript (ES6+), Dynamic DOM Manipulation
* **Graphics Rendering:** HTML5 Canvas API
* **Math Typesetting:** MathJax v3 Integration
